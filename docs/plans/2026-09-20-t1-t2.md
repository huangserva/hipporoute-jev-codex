# T2 Missing Completed and T1 Long-Parent Fan-out Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Diagnose and fix missing `response.completed` accounting, then measure whether subagent model routing remains economical with 30k/80k/150k parent contexts and whether `fork_turns=none` removes cold-history cost.

**Architecture:** Add sentinel-gated raw upstream stream capture at the router's `HTTPResponse` read boundary and use it to identify the failing layer. After the T2 regression is fixed and verified, add an isolated long-context benchmark driver that rotates shadow/full-history/no-history settings and derives all metrics from decision logs and automated checks.

**Tech Stack:** Python 3.11+ standard library, `unittest`, Codex CLI 0.155.1, Responses SSE, project-level Codex PreToolUse hooks.
